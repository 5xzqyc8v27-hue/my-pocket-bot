# Инструкция: что поставить, что загрузить, как настроить

## 1. Установка (один раз)

```bash
bash setup.sh              # ffmpeg, Python-окружение, все библиотеки
bash setup.sh --local-ai   # то же + локальная нейросеть Ollama (бесплатно, ~5 ГБ)
```

Запуск панели:

```bash
source .venv/bin/activate && python -m clipper.server
```

Откройте http://127.0.0.1:8765 → вкладка **«Настройка»**. Панель сама проверит, что
установлено, и для каждого недостающего пункта покажет команду.

## 2. Нейросети — что нужно, а что нет

| Что | Зачем | Обязательно? | Стоимость |
|---|---|---|---|
| faster-whisper | Субтитры и выбор моментов по смыслу | Желательно | Бесплатно, локально |
| Claude по подписке | Выбор моментов, хуки, разбор примеров | Один из трёх | Входит в подписку |
| Claude по API | То же | Один из трёх | Кредиты |
| Ollama | Выбор моментов локально | Один из трёх | Бесплатно |

Без нейросетей панель тоже работает: моменты ищутся по громкости и плотности речи.

## 3. Что загрузить во вкладку «Материалы»

Для каждого стримера заведите свой раздел (поле «Новый стример») и положите:

| Тип | Что класть | Где используется |
|---|---|---|
| Фото и вырезки | Фото стримера, PNG-вырезки | Низ кадра в подборках «ТОП N» |
| Шрифты | `.ttf` / `.otf` с кириллицей | Титры подборок; имя шрифта — в поле «Шрифт» |
| Залипалки | Зацикленные видео | Раскладка «сплит» (путь указывается при добавлении исходника) |
| Баннеры | PNG с прозрачностью | Поле «Баннер» во вкладке «Уникализация» |
| Эмодзи, звуки, шаблоны | Свои паки | Пока только хранятся, в монтаж подключатся позже |

## 4. Рабочий порядок

1. **Примеры.** Дайте 3–5 роликов конкурентов → получите пресеты и описание приёмов.
2. **Исходник.** Ссылка или файл, стример, «Что искать» (смешное, фейлы, эмоции и т.д.).
3. **Моменты.** Фильтр по типу, правка хука (или один из вариантов), границы.
4. **Оформление.** Пресет → подстройка с предпросмотром → «Сохранить».
5. **Монтаж.** Одиночные ролики или подборка «ТОП N».
6. **Проверка** уникальности и, при желании, доводка в CapCut.

### Автоматический режим

Вкладка **«Стримеры»** → имя, площадка, ник канала → «Добавить». Панель должна оставаться
запущенной, а макбук — не спать: запись идёт только пока работает программа. Один час эфира
в хорошем качестве занимает примерно 2–4 ГБ, поэтому следите за диском или включите «Очистку».

## 5. Чтобы ролики не были под копирку

- Держите включённой галочку **«Разнообразить ролики»**: у каждого ролика пачки свои
  положение и стиль текста, движение камеры, скорость и цвет — раскладка и тема те же.
- Чередуйте форматы: одиночный момент, «ТОП N», сплит с залипалкой.
- Заведите 2–3 пресета на стримера и меняйте их по дням.
- Пишите разные хуки: вопрос, интрига, цитата — варианты уже предложены под каждым моментом.
- Самое весомое отличие — ваш собственный вклад: свой комментарий, подборка, заголовок.
  Площадки оценивают именно его, а не цвет субтитров; гарантий от пессимизации нет.

## 6. Движение камеры

Вкладка «Уникализация» → «Движение камеры»:

- **Плавный наезд** — кадр медленно приближается весь ролик (подкасты, разговорные моменты).
- **Резкие наезды** — короткий зум на самых громких местах (крики, смех, реакции).
- **Оба** — вместе. «Сила наезда» регулирует глубину.

## 7. Бесплатные источники

| Что | Где | На что смотреть |
|---|---|---|
| Звуки | Mixkit, Pixabay, Freesound | У Freesound лицензия у каждого файла своя |
| Переходы, оверлеи | PremiumBeat (бесплатные подборки), Mixkit, Freevisuals | Лицензию проверять у каждого пака |
| Шрифты | Google Fonts | Нужна кириллица |
| Эмодзи | Noto Emoji, OpenMoji | Открытые лицензии |
| Озвучка | Kokoro, XTTS v2 (локально), Fish Audio, SpeechKit | Клонирование голоса — только с согласия |
| Картинки локально | FLUX schnell / klein, SDXL (через ComfyUI или Draw Things) | Лицензия зависит от версии модели |
| Видео локально | Wan 2.2, LTX-Video (через ComfyUI) | Тяжёлые: рассчитаны на видеокарты от 8–16 ГБ |

Мемные звуки, музыка и чужие ролики обычно защищены авторским правом.
