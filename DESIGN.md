# Оформление панели

Система собрана по образцу Linear из открытой коллекции
[awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT) и правилам движения из
[design-motion-principles](https://github.com/kylezantos/design-motion-principles) (MIT).
Все значения — переменные в начале `clipper/web/index.html`.

## Цвет

| Роль | Переменная | Значение |
|---|---|---|
| Фон страницы | `--bg` | `#08090b` |
| Панели, карточки | `--panel` | `#101216` |
| Вложенные блоки, поля | `--panel2` | `#16191f` |
| Наведение, всплывающие | `--panel3` | `#1d2128` |
| Тонкая граница | `--line` | `#23272f` |
| Граница при наведении | `--line2` | `#2f343d` |
| Основной текст | `--text` | `#f7f8f8` |
| Второстепенный текст | `--mute` | `#8a8f98` |
| Акцент | `--accent` | `#a9dc5a` |

- Один акцентный цвет. Он только на главной кнопке экрана, активном пункте меню, оценке и фокусе.
- Глубина — ступенями фона и тонкими границами, без теней и градиентов.
- Зелёный, жёлтый и красный — только как состояние (готово, внимание, ошибка).

## Текст и форма

- Шрифт системный (на macOS — San Francisco): панель работает без интернета и выглядит родной для
  системы. Заголовки 600 с отрицательным межбуквенным интервалом.
- Подписи разделов — обычным регистром, 13px, без разрядки и заглавных.
- Скругления: кнопки и поля 8px, карточки 12px, окна 16px, значки состояния — капсулой.
- На экране одна главная (акцентная) кнопка; остальные — нейтральные.

## Движение

- Наведение и переключение: 140 мс. Окна и уведомления: 160–180 мс. Ничего дольше 300 мс.
- Кривая `cubic-bezier(.2,.8,.2,1)`; анимируются только прозрачность и сдвиг.
- Нет пульсирующих точек, увеличения карточек при наведении и появления «лесенкой».
- При системной настройке «уменьшить движение» анимации отключаются.

## Устройство экранов

- На экране — только основное действие; редкие настройки открываются отдельным окном.
- Списки — компактными строками, подробности по кнопке.
- Сообщения — всплывающими уведомлениями, которые исчезают сами.

## Принятые решения (проход по правилам unslop)

Проверено вручную по списку признаков «нейросетевого» интерфейса из скилла
[unslop](https://github.com/broomva/skills) (MIT). Список — детектор, а не запрет: каждое решение
ниже принято осознанно и записано здесь.

| Признак | Решение |
|---|---|
| Шрифт по умолчанию (Inter и подобные) | Системный шрифт, см. выше |
| Заглавные подписи с разрядкой | Убраны: обычный регистр |
| Цветная полоса слева у активного пункта и уведомлений | Убрана: активный пункт выделен фоном |
| Карточки внутри карточек | Список моментов — без общей карточки; в окнах вложенные карточки плоские |
| Неоновые цвета | Акцент приглушён; цвет несёт смысл (действие или состояние), а не украшает |
| Значки-символы (звёздочки, галочки) | Оценка — число в плашке с цифрами одной ширины; шаги — номерами |
| Градиенты, свечение, стекло, тени на всём | Не используются |
| Тире в текстах | Оставлено: в русском языке это обычный знак препинания |
| Анимации | Только короткие переходы; покой по умолчанию; учитывается «уменьшить движение» |
| Пустые состояния и ошибки | Есть у каждого списка; ошибки — уведомлением с текстом причины |

Автоматическую проверку скилла (его скрипты) запустить не удалось — пройдено вручную.
