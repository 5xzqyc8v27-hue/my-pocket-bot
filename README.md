# my-pocket-bot — авто-нарезчик

Берёт длинное видео (файл или ссылку), находит сильные моменты и монтирует из них
вертикальные ролики 9:16 с надписью-хуком и субтитрами.

Подробная инструкция — что поставить, что загрузить и как настроить — в [docs/GUIDE.md](docs/GUIDE.md).

## Установка (macOS)

Быстро: `bash setup.sh` (добавьте `--local-ai` для локальной нейросети). Вручную:

```bash
brew install ffmpeg
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Панель

```bash
python -m clipper.server
```

Открыть http://127.0.0.1:8765. Короткий путь: «+ Новый исходник» → ссылка или файл → сколько
роликов и какой длины → «Найти моменты». По умолчанию ролики сразу монтируются в выбранном
оформлении и появляются карточками в проекте: скачать по одному или все архивом.

Всё остальное открывается отдельными окнами и только когда нужно:

- **«Изменить»** у момента — границы, варианты хука, сообщение из чата, картинка, вставки.
- **«Настроить»** — оформление с живым предпросмотром (раскладка, хук, субтитры, уникализация).
- **«Собрать ТОП»** — подборка из отмеченных моментов.

Громкость роликов выравнивается до −14 LUFS — стандарта площадок.

### Стримеры (автоконвейер)

Вкладка «Стримеры»: добавьте канал Twitch или Kick (ник или ссылка). Аккаунт и ключи Twitch
не нужны — эфир проверяется и пишется через `streamlink`. Дальше панель сама:

1. **Эфир** — раз в минуту проверяет, идёт ли стрим, и пишет его кусками (по умолчанию по 10 минут).
2. **Монтаж** — в каждом готовом куске находит моменты и монтирует лучшие (пресет, число
   роликов с куска, порог оценки и фильтр мата настраиваются у стримера).
3. **Публикация** — пока не подключена, ролики забираются из проекта вручную.
4. **Очистка** — по желанию удаляет записанный кусок сразу после монтажа.

Площадка «Готовая запись эфира» прогоняет через тот же конвейер уже скачанный файл.

### Правила конкурса стримера

В настройках стримера есть блок «Правила конкурса» (кнопка «Заполнить правилами Злого» подставляет
правила его конкурса нарезок). Правила — подсказки, а не запреты: панель делает ролик так, как вы
просили, и только предупреждает.

- **Обязательная ссылка** (например `twitch: ZLOYn`) дописывается в подпись каждого ролика.
- **Сплит с отвлекающим видео и баннеры** монтируются как обычно, но в статусе проекта появляется
  предупреждение, что по правилам такой ролик могут не принять.
- **Темы, за которые могут не заплатить** (политика, запрещённые вещества и т. п.): такие моменты
  не отбрасываются, а получают пометку «риск по правилам».
- **Выплата.** Для вышедшего ролика во вкладке «Публикация» впишите ссылку и просмотры — панель
  покажет, какой порог взят, сколько положено (нарезка или мем-видео), сколько дней осталось до
  конца приёма и что выгоднее: подавать сейчас или ждать следующего порога.

### Рассказ

Вкладка «Рассказ» — ролик с закадровым голосом: сценарий (свой или через Claude по теме),
озвучка (бесплатные онлайн-голоса через `edge-tts`, встроенный голос macOS или свой файл из
«Материалы → Озвучка»), под каждую фразу —
случайный кусок из выбранных исходников на весь кадр, субтитры по слову, по желанию музыка.

### Публикация

Кнопка «В очередь» у готового ролика ставит его в расписание для аккаунтов стримера: равномерные
слоты по дням (по умолчанию 2 в день с 10 до 22). Вкладка «Публикация» показывает расписание.

**Вручную** (по умолчанию): когда подходит время — скачиваете ролик, копируете подпись,
выкладываете и жмёте «Выложено».

**Автоматически через Blotato:**

1. В кабинете Blotato подключите соцсети и создайте ключ API.
2. Запустите панель с ключом: `BLOTATO_API_KEY=ваш_ключ python -m clipper.server`.
3. Вкладка «Аккаунты» → у аккаунта кнопка «Автовыкладка» → выберите соответствующий аккаунт
   Blotato и включите галочку.

Ролики этого аккаунта будут публиковаться сами в назначенное время. Ключ нигде не сохраняется.
Клиент написан по коду официального пакета Blotato для n8n; ролики больше 15 МБ перед отправкой
сжимаются.

### Умный кроп

При анализе панель ищет лицо стримера: вебка стоит на месте, а лица в игре двигаются, поэтому
берётся самое устойчивое. По лицу сама определяется область вебки (раскладки «Вебка + игра» и
«Чат + реакция») или положение кадра (раскладка «Без вебки»). Выключается галочкой «Умный кроп» в
оформлении; если выделить область мышкой, он отключается сам. Нужен OpenCV 4
(`opencv-python-headless<5`).

### Запинки и оговорки

Панель находит в речи места, где стример запнулся, оговорился и поправился или повторил слово
или фразу. На них можно повесить:

- **двойной наезд камеры** — галочка «Двойной наезд на запинках и повторах» (вкладка
  «Уникализация»): шаг ближе, ещё ближе, резкий возврат. Если запинок нет, берутся самые громкие места;
- **мем и звук** — кнопка «Авто» у вставок момента ставит их в первую очередь на запинки.

### Удобства оформления

- **Выделение мышкой.** Для раскладок с вебкой — кнопка «Выделить вебку на кадре мышкой»: рисуете
  прямоугольник на кадре исходника. Для раскладки без вебки — перетаскиваете рамку влево-вправо.
- **Смена сцены.** «В громкие моменты разворачивать вебку на весь кадр» (вкладка «Раскладка»).
- **Закрывать мат** в субтитрах звёздочками (вкладка «Субтитры»).
- **Одна надпись для всех роликов** — поле в окне оформления.
- Цвета выбираются кружками, шрифт — из списка установленных в системе.

### Тизер

В оформлении, вкладка «Хук» → «Тизер»: самое громкое место ролика на 1–2 секунды ставится в самое
начало, затем ролик идёт с начала.

### История трансляций и клипы зрителей

У стримера на Twitch кнопка «История и клипы» открывает два списка:

- **Трансляции целиком** — прошедшие эфиры с датой, длительностью и просмотрами. Для них
  дополнительно скачивается чат: по нему находятся прочитанные сообщения и всплески активности.
- **Клипы зрителей** — самые просматриваемые клипы канала за сутки, неделю, месяц или всё время.
  Зрители уже отобрали смешное; остаётся смонтировать в своём оформлении.

Отмечаете нужное, выбираете формат (пресет), что искать и сколько моментов — «В монтаж».

### Сигналы по звуку и вставки по смыслу

- При поиске моментов панель находит по звуку эмоциональные всплески (смех, крик, громкая речь) и
  передаёт их нейросети как подсказку, где искать. Оценка по звуку приблизительная.
- Кнопка «Авто» у вставок: Claude читает реплики момента и список файлов из материалов и подбирает
  мем, эмодзи или звук под смысл фразы. Поэтому называйте файлы понятно: `bruh.mp3`,
  `confused_cat.mp4`, `sad_violin.mp3`. Без Claude вставки ставятся случайно на запинки и громкие места.

### Картинка под момент

В раскладке «Чат + реакция» низ кадра — картинка. Её можно выбрать для каждого момента из
материалов. Кнопка «Идея картинки» просит Claude придумать смешной образ стримера под сообщение
и выдаёт готовый запрос для генератора картинок — саму картинку вы делаете в своём генераторе
и загружаете в «Материалы».

### Подборки по темам

Вкладка «Подборки»: Claude читает расшифровки всех трансляций стримера и находит темы —
повторяющиеся приколы, словечки, похожие реакции. Тема — 3–6 коротких кусков из разных
трансляций под одним заголовком («Искусство обзывания», «3 вида одноклассников»). Кнопка
«Смонтировать» склеивает их встык в выбранном оформлении, по желанию с тихой музыкой из
«Материалы → Музыка».

Чтобы из одной трансляции получить ролики в разных стилях, выберите у кнопки монтажа
«Стилей на каждый момент»: тот же момент дополнительно смонтируется в других пресетах.

### Чат + реакция

Вместе с эфиром Twitch пишется чат (в режиме гостя, аккаунт не нужен). В каждом куске панель
ищет места, где стример прочитал сообщение вслух и ответил, и добавляет их в моменты с меткой
«чат». Раскладка «Чат + реакция» (пресет `chat`): вебка сверху, плашка с сообщением, снизу —
случайное фото стримера из материалов. Ник и текст сообщения можно вписать и вручную в карточке
момента. В автоконвейере ролики по чату сами не монтируются — их сначала просматривает человек.

### Проверки: уникальность, охваты, IP

- **Уникальность ролика** — кнопка «Проверить» у готового ролика: насколько кадры отличаются от исходника.
- **Охваты аккаунта** (вкладка «Аккаунты» → «Проверить охваты») — просмотры трёх последних роликов
  сравниваются с обычным уровнем аккаунта. Резкий провал — признак ограничения показов. Площадки о
  теневом бане не сообщают, поэтому это оценка по косвенному признаку. Работает для YouTube и TikTok.
- **IP-адрес** (там же) — как площадки видят адрес этого компьютера: обычный, мобильный или адрес
  дата-центра, VPN, прокси.

### Тренды

Вкладка «Тренды»: добавьте каналы игровых блогеров (ссылка или `@ник`) и темы (поисковый
запрос, например `GTA 6 shorts`). Раз в 3 часа панель собирает просмотры через `yt-dlp` и
показывает топ за 24 часа, 48 часов и месяц; рост считается по разнице между сборами.
Любой ролик можно одной кнопкой взять в работу или разобрать как пример.

### Вставки

У каждого момента есть «Вставки»: мем-видео, картинка, эмодзи или звук в нужную секунду.
Кнопка «Авто» ставит случайный мем и звук из материалов на самые громкие места.
Материалы можно загрузить файлами или скачать по ссылке прямо в нужный раздел.

### Аккаунты и пользователи

Вкладка «Аккаунты» — учёт: площадка, имя аккаунта, почта, устройство, стример. Пароли не хранятся.

Отдельное рабочее пространство для другого человека (свои проекты, стримеры, аккаунты, файлы):

```bash
CLIPPER_PASSWORD=пароль python -m clipper.server --profile drug --port 8766
```

### Подборка «ТОП N»

Отметьте 2–10 моментов, введите заголовок — получится ролик со списком мест, который
заполняется по ходу (лучший момент в конце), на размытом фоне, с фото стримера внизу.

### Материалы

Вкладка «Материалы»: свои файлы — общие и отдельно под каждого стримера (фото и вырезки,
эмодзи и стикеры, шрифты, звуки, баннеры, залипалки, шаблоны). Лежат в `data/assets/<стример>/`.
Сейчас в монтаже используются фото (в топах) и шрифты (в титрах топов).

### Импорт пака с Google Диска или Яндекс Диска

Вкладка «Материалы» → «Импорт пака»: вставляете ссылку на общую папку, и файлы сами
раскладываются по разделам — мемы, звуки, музыка, шрифты, фоны, иконки. Подпапка попадает в имя
файла («Вуши_Базовый_вуш_1.mp3»), чтобы вставки подбирались по смыслу. 3D-модели, пресеты After
Effects и заготовки для ручного моушн-дизайна пропускаются. Повторный импорт докачивает только новое.

Что ещё берётся из пака:

- **Цветокор (LUT)** — файлы `.cube`. Выбираются в оформлении: «Цветокор» и «Сила цветокора».
- **Эффекты и переходы** — футажи на чёрном фоне (глитч, вспышки, пыль). Добавляются как вставка
  в момент и накладываются осветлением на весь кадр.
- **Анимированные эмодзи** — версии с прозрачностью (`.mov`) при импорте сжимаются в лёгкий `.webm`.
  Эмодзи на зелёном фоне тоже работают: фон убирается сам.

### Спокойная нарезка одним роликом

Пресет `calm`: медленный наезд камеры, субтитры без подпрыгивания, мат закрыт звёздочками, приглушённый
цвет. Галочка «Одним роликом» рядом с кнопкой «Смонтировать все» склеивает отмеченные моменты по порядку
эфира. Переходы задаются в оформлении («Переходы в подборках»): встык или мягкое затемнение — то же
работает в подборках по темам.

Из одного пака берётся не больше 60 LUT, 150 эффектов и 60 фонов, файлы крупнее 80 МБ пропускаются.

Шрифты из материалов появляются первыми в списке шрифтов оформления и работают без установки в систему.

### Примеры

Вкладка «Примеры»: даёте ролик конкурента (ссылка или файл) — Claude смотрит раскадровку,
определяет формат, описывает приёмы монтажа и сохраняет пресет с похожим оформлением.

### CapCut

Кнопка «Открыть момент в CapCut» создаёт проект CapCut с отрезком видео, хуком и
субтитрами на отдельных дорожках — его можно доделать руками. Официального API у CapCut
нет, проект собирается неофициальной библиотекой `pycapcut`; на новых версиях CapCut
формат может не подойти.

## Запуск из терминала


```bash
# найти 5 моментов и смонтировать
python -m clipper run video.mp4 --count 5 --preset center

# по ссылке, сплит-экран с залипалкой снизу
python -m clipper run "https://youtu.be/..." --preset split --filler loops/satisfying.mp4

# один отрезок вручную
python -m clipper clip video.mp4 --start 120 --end 150 --title "Надпись на экране"
```

Ролики и `moments.json` (оценка, название, подпись, хэштеги) появляются в `out/<имя видео>/`.

## Выбор моментов

Четыре способа, `--picker auto` (по умолчанию) берёт первый доступный и при сбое
переходит к следующему:

| `--picker` | На чём работает | Что нужно |
|---|---|---|
| `claude` | Claude API, тратит кредиты | `export ANTHROPIC_API_KEY=...` (модель — `CLIPPER_MODEL`) |
| `claude-cli` | Подписка Claude через Claude Code, кредиты не тратит | Установить Claude Code и один раз войти (`claude`, затем `/login`) |
| `ollama` | Локальная нейросеть, бесплатно и без интернета | `brew install ollama && ollama pull qwen2.5:7b` (модель — `CLIPPER_OLLAMA_MODEL`) |
| `heuristic` | Без нейросети: всплески громкости и плотность речи | Ничего |

Расшифровка речи и монтаж всегда идут локально и ничего не стоят. Основной движок распознавания —
`faster-whisper`; если он не смог скачать модель, автоматически включается запасной `sherpa-onnx`
с моделью с GitHub (кладётся в папку `models/`). Движок можно задать явно: `CLIPPER_STT=sherpa`.

## Раскладки (`presets/*.json`)

| Пресет | Что делает |
|---|---|
| `center` | Видео 16:9 по центру на размытом фоне |
| `square` | Квадрат по центру |
| `split` | Сверху ролик, снизу залипалка (`--filler`) |
| `reaction` | Вебка стримера и игра друг над другом; область вебки задаётся в `webcam` |
| `full` | Без вебки: вертикальная часть кадра на весь экран, положение выбирается мышкой |
| `chat` | Вебка, плашка с сообщением из чата, картинка снизу |
| `neon` | Вебка + игра, неоновый хук на стыке, субтитры по одному слову, ник поверх кадра |

В пресете настраиваются шрифт, размер, цвет и положение надписи и субтитров,
масштаб, размытие фона, баннер. Свой пресет — скопировать json и передать `--preset путь.json`.
