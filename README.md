# my-pocket-bot — авто-нарезчик

Берёт длинное видео (файл или ссылку), находит сильные моменты и монтирует из них
вертикальные ролики 9:16 с надписью-хуком и субтитрами.

Подробная инструкция — что поставить, что загрузить и как настроить — в [docs/GUIDE.md](docs/GUIDE.md).

## Установка (macOS)

Быстро: `bash setup.sh` (добавьте `--local-ai` для локальной нейросети). Вручную:

```bash
brew install ffmpeg
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Панель (всё в одном окне)

```bash
python -m clipper.server
```

Открыть http://127.0.0.1:8765. В панели: добавление исходника (ссылка, путь или файл),
список найденных моментов с оценкой и вариантами хуков, редактор оформления с живым
предпросмотром (раскладка, хук, субтитры, уникализация, кнопка «Рандом»), сохранение
пресетов, монтаж выбранных моментов, библиотека готовых роликов и проверка уникальности.

Проверка уникальности сравнивает кадры ролика с исходным отрезком: 0% — копия,
100% — картинка совсем другая. Это собственная оценка, алгоритмы площадок она не повторяет.

### Стримеры (автоконвейер)

Вкладка «Стримеры»: добавьте канал Twitch или Kick (ник или ссылка). Аккаунт и ключи Twitch
не нужны — эфир проверяется и пишется через `streamlink`. Дальше панель сама:

1. **Эфир** — раз в минуту проверяет, идёт ли стрим, и пишет его кусками (по умолчанию по 10 минут).
2. **Монтаж** — в каждом готовом куске находит моменты и монтирует лучшие (пресет, число
   роликов с куска, порог оценки и фильтр мата настраиваются у стримера).
3. **Публикация** — пока не подключена, ролики забираются из проекта вручную.
4. **Очистка** — по желанию удаляет записанный кусок сразу после монтажа.

Площадка «Готовая запись эфира» прогоняет через тот же конвейер уже скачанный файл.

### Рассказ

Вкладка «Рассказ» — ролик с закадровым голосом: сценарий (свой или через Claude по теме),
озвучка (встроенный голос macOS или свой файл из «Материалы → Озвучка»), под каждую фразу —
случайный кусок из выбранных исходников на весь кадр, субтитры по слову, по желанию музыка.

### Публикация

Кнопка «В очередь» у готового ролика ставит его в расписание для аккаунтов стримера: равномерные
слоты по дням (по умолчанию 2 в день с 10 до 22). Вкладка «Публикация» показывает расписание по
дням; когда подходит время — скачиваете ролик, копируете подпись, выкладываете и жмёте «Выложено».
«Удалить вышедшие» чистит с диска ролики, вышедшие больше суток назад. Автовыкладка не подключена.

### Удобства оформления

- **Выделение мышкой.** Для раскладок с вебкой — кнопка «Выделить вебку на кадре мышкой»: рисуете
  прямоугольник на кадре исходника. Для раскладки без вебки — перетаскиваете рамку влево-вправо.
- **Смена сцены.** «В громкие моменты разворачивать вебку на весь кадр» (вкладка «Раскладка»).
- **Закрывать мат** в субтитрах звёздочками (вкладка «Субтитры»).
- **Одна надпись для всех роликов** — поле над кнопкой монтажа.
- Цвета выбираются кружками, шрифт — из списка установленных в системе.

### Тизер

В оформлении, вкладка «Хук» → «Тизер»: самое громкое место ролика на 1–2 секунды ставится в самое
начало, затем ролик идёт с начала.

### История трансляций

У стримера на Twitch есть кнопка «Показать историю трансляций»: список прошедших эфиров с датой,
длительностью и просмотрами. Отмечаете нужные, выбираете формат (пресет), что искать и сколько
моментов — кнопка «В монтаж» скачивает их и обрабатывает. Для прошедших трансляций Twitch
дополнительно скачивается чат: по нему находятся прочитанные сообщения и всплески активности.

### Картинка под момент

В раскладке «Чат + реакция» низ кадра — картинка. Её можно выбрать для каждого момента из
материалов. Кнопка «Идея картинки» просит Claude придумать смешной образ стримера под сообщение
и выдаёт готовый запрос для генератора картинок — саму картинку вы делаете в своём генераторе
и загружаете в «Материалы».

### Подборки по темам

Вкладка «Подборки»: Claude читает расшифровки всех трансляций стримера и находит темы —
повторяющиеся приколы, словечки, похожие реакции. Тема — 3–6 коротких кусков из разных
трансляций под одним заголовком («Искусство обзывания», «3 вида одноклассников»). Кнопка
«Смонтировать» склеивает их встык в выбранном оформлении, по желанию с тихой музыкой из
«Материалы → Музыка».

Чтобы из одной трансляции получить ролики в разных стилях, выберите у кнопки монтажа
«Стилей на каждый момент»: тот же момент дополнительно смонтируется в других пресетах.

### Чат + реакция

Вместе с эфиром Twitch пишется чат (в режиме гостя, аккаунт не нужен). В каждом куске панель
ищет места, где стример прочитал сообщение вслух и ответил, и добавляет их в моменты с меткой
«чат». Раскладка «Чат + реакция» (пресет `chat`): вебка сверху, плашка с сообщением, снизу —
случайное фото стримера из материалов. Ник и текст сообщения можно вписать и вручную в карточке
момента. В автоконвейере ролики по чату сами не монтируются — их сначала просматривает человек.

### Тренды

Вкладка «Тренды»: добавьте каналы игровых блогеров (ссылка или `@ник`) и темы (поисковый
запрос, например `GTA 6 shorts`). Раз в 3 часа панель собирает просмотры через `yt-dlp` и
показывает топ за 24 часа, 48 часов и месяц; рост считается по разнице между сборами.
Любой ролик можно одной кнопкой взять в работу или разобрать как пример.

### Вставки

У каждого момента есть «Вставки»: мем-видео, картинка, эмодзи или звук в нужную секунду.
Кнопка «Авто» ставит случайный мем и звук из материалов на самые громкие места.
Материалы можно загрузить файлами или скачать по ссылке прямо в нужный раздел.

### Аккаунты и пользователи

Вкладка «Аккаунты» — учёт: площадка, имя аккаунта, почта, устройство, стример. Пароли не хранятся.

Отдельное рабочее пространство для другого человека (свои проекты, стримеры, аккаунты, файлы):

```bash
CLIPPER_PASSWORD=пароль python -m clipper.server --profile drug --port 8766
```

### Подборка «ТОП N»

Отметьте 2–10 моментов, введите заголовок — получится ролик со списком мест, который
заполняется по ходу (лучший момент в конце), на размытом фоне, с фото стримера внизу.

### Материалы

Вкладка «Материалы»: свои файлы — общие и отдельно под каждого стримера (фото и вырезки,
эмодзи и стикеры, шрифты, звуки, баннеры, залипалки, шаблоны). Лежат в `data/assets/<стример>/`.
Сейчас в монтаже используются фото (в топах) и шрифты (в титрах топов).

### Примеры

Вкладка «Примеры»: даёте ролик конкурента (ссылка или файл) — Claude смотрит раскадровку,
определяет формат, описывает приёмы монтажа и сохраняет пресет с похожим оформлением.

### CapCut

Кнопка «Открыть момент в CapCut» создаёт проект CapCut с отрезком видео, хуком и
субтитрами на отдельных дорожках — его можно доделать руками. Официального API у CapCut
нет, проект собирается неофициальной библиотекой `pycapcut`; на новых версиях CapCut
формат может не подойти.

## Запуск из терминала


```bash
# найти 5 моментов и смонтировать
python -m clipper run video.mp4 --count 5 --preset center

# по ссылке, сплит-экран с залипалкой снизу
python -m clipper run "https://youtu.be/..." --preset split --filler loops/satisfying.mp4

# один отрезок вручную
python -m clipper clip video.mp4 --start 120 --end 150 --title "Надпись на экране"
```

Ролики и `moments.json` (оценка, название, подпись, хэштеги) появляются в `out/<имя видео>/`.

## Выбор моментов

Четыре способа, `--picker auto` (по умолчанию) берёт первый доступный и при сбое
переходит к следующему:

| `--picker` | На чём работает | Что нужно |
|---|---|---|
| `claude` | Claude API, тратит кредиты | `export ANTHROPIC_API_KEY=...` (модель — `CLIPPER_MODEL`) |
| `claude-cli` | Подписка Claude через Claude Code, кредиты не тратит | Установить Claude Code и один раз войти (`claude`, затем `/login`) |
| `ollama` | Локальная нейросеть, бесплатно и без интернета | `brew install ollama && ollama pull qwen2.5:7b` (модель — `CLIPPER_OLLAMA_MODEL`) |
| `heuristic` | Без нейросети: всплески громкости и плотность речи | Ничего |

Расшифровка речи и монтаж всегда идут локально и ничего не стоят.

## Раскладки (`presets/*.json`)

| Пресет | Что делает |
|---|---|
| `center` | Видео 16:9 по центру на размытом фоне |
| `square` | Квадрат по центру |
| `split` | Сверху ролик, снизу залипалка (`--filler`) |
| `reaction` | Вебка стримера и игра друг над другом; область вебки задаётся в `webcam` |
| `full` | Без вебки: вертикальная часть кадра на весь экран, положение выбирается мышкой |
| `chat` | Вебка, плашка с сообщением из чата, картинка снизу |
| `neon` | Вебка + игра, неоновый хук на стыке, субтитры по одному слову, ник поверх кадра |

В пресете настраиваются шрифт, размер, цвет и положение надписи и субтитров,
масштаб, размытие фона, баннер. Свой пресет — скопировать json и передать `--preset путь.json`.
