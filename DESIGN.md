# Оформление панели

Система собрана по образцу Linear из открытой коллекции
[awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT) и правилам движения из
[design-motion-principles](https://github.com/kylezantos/design-motion-principles) (MIT).
Все значения — переменные в начале `clipper/web/index.html`.

## Цвет

| Роль | Переменная | Значение |
|---|---|---|
| Фон страницы | `--bg` | `#08090b` |
| Панели, карточки | `--panel` | `#101216` |
| Вложенные блоки, поля | `--panel2` | `#16191f` |
| Наведение, всплывающие | `--panel3` | `#1d2128` |
| Тонкая граница | `--line` | `#23272f` |
| Граница при наведении | `--line2` | `#2f343d` |
| Основной текст | `--text` | `#f7f8f8` |
| Второстепенный текст | `--mute` | `#8a8f98` |
| Акцент | `--accent` | `#b8f04a` |

- Один акцентный цвет. Он только на главной кнопке экрана, активном пункте меню, оценке и фокусе.
- Глубина — ступенями фона и тонкими границами, без теней и градиентов.
- Зелёный, жёлтый и красный — только как состояние (готово, внимание, ошибка).

## Текст и форма

- Шрифт: Inter, затем системный. Заголовки 600 с отрицательным межбуквенным интервалом,
  надзаголовки разделов — 12px, заглавные, интервал +0.4px.
- Скругления: кнопки и поля 8px, карточки 12px, окна 16px, значки состояния — капсулой.
- На экране одна главная (акцентная) кнопка; остальные — нейтральные.

## Движение

- Наведение и переключение: 140 мс. Окна и уведомления: 160–180 мс. Ничего дольше 300 мс.
- Кривая `cubic-bezier(.2,.8,.2,1)`; анимируются только прозрачность и сдвиг.
- Нет пульсирующих точек, увеличения карточек при наведении и появления «лесенкой».
- При системной настройке «уменьшить движение» анимации отключаются.

## Устройство экранов

- На экране — только основное действие; редкие настройки открываются отдельным окном.
- Списки — компактными строками, подробности по кнопке.
- Сообщения — всплывающими уведомлениями, которые исчезают сами.
